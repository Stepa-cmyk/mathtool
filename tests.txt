НАБОР ТЕСТОВ ДЛЯ ПРИЛОЖЕНИЯ MATHTOOL
=====================================

Во всех примерах команда запускается из каталога проекта.
Сообщения с пометкой stderr должны выводиться в поток ошибок.


Тест 1. Справка при запуске без параметров
Команда:
  python mathtool.py
Ожидается:
  Текст справки с назначением программы и способами запуска.
  Код возврата: 0.


Тест 2. Справка с параметром --help
Команда:
  python mathtool.py --help
Ожидается:
  Текст справки с назначением программы и способами запуска.
  Код возврата: 0.


Тест 3. Неизвестная команда
Команда:
  python mathtool.py calculate
Ожидается (stderr):
  ОШИБКА: неизвестная команда 'calculate'
  Код возврата: 1.


Тест 4. Пропущен параметр -c
Команда:
  python mathtool.py solve -a 1 -b 2
Ожидается (stderr):
  ОШИБКА: неверный набор параметров
  Код возврата: 1.


Тест 5. Передан лишний параметр
Команда:
  python mathtool.py solve -a 1 -b 2 -c 3 extra
Ожидается (stderr):
  ОШИБКА: неверный набор параметров
  Код возврата: 1.


Тест 6. Неизвестный параметр
Команда:
  python mathtool.py solve -x 1 -b 2 -c 3
Ожидается (stderr):
  ОШИБКА: неизвестный параметр
  Код возврата: 1.


Тест 7. Коэффициент не является целым числом
Команда:
  python mathtool.py solve -a abc -b 1 -c 1
Ожидается (stderr):
  ОШИБКА: коэффициент не является целым числом
  Код возврата: 1.


Тест 8. Коэффициент находится вне допустимого диапазона
Команда:
  python mathtool.py solve -a 50000 -b 1 -c 1
Ожидается (stderr):
  ОШИБКА: значение вне допустимого диапазона
  Код возврата: 1.


Тест 9. Квадратное уравнение с двумя корнями
Команда:
  python mathtool.py solve -a 1 -b -3 -c 2
Ожидается:
  Уравнение квадратное
  D = 1
  x1 = 2.000
  x2 = 1.000
  Код возврата: 0.


Тест 10. Квадратное уравнение с одним корнем
Команда:
  python mathtool.py solve -a 1 -b -2 -c 1
Ожидается:
  Уравнение квадратное
  D = 0
  x = 1.000
  Код возврата: 0.


Тест 11. Квадратное уравнение без действительных корней
Команда:
  python mathtool.py solve -a 1 -b 0 -c 5
Ожидается:
  Уравнение квадратное
  D = -20
  Действительных корней нет
  Код возврата: 0.


Тест 12. Линейное уравнение
Команда:
  python mathtool.py solve -a 0 -b 2 -c -4
Ожидается:
  Уравнение линейное
  x = 2.000
  Код возврата: 0.


Тест 13. Неизвестное отсутствует, C = 0
Команда:
  python mathtool.py solve -a 0 -b 0 -c 0
Ожидается (stderr):
  ОШИБКА: это не уравнение, неизвестное отсутствует
  Код возврата: 1.


Тест 14. Неизвестное отсутствует, C != 0
Команда:
  python mathtool.py solve -a 0 -b 0 -c 7
Ожидается (stderr):
  ОШИБКА: это не уравнение, неизвестное отсутствует
  Код возврата: 1.


Тест 15. Ввод коэффициентов с клавиатуры
Команда:
  python mathtool.py solve
Ввод пользователя:
  A: 1
  B: -3
  C: 2
Ожидается:
  Уравнение квадратное
  D = 1
  x1 = 2.000
  x2 = 1.000
  Код возврата: 0.


Тест 16. Некорректный ввод с клавиатуры
Команда:
  python mathtool.py solve
Ввод пользователя:
  A: abc
Ожидается (stderr):
  ОШИБКА: коэффициент не является целым числом
  Код возврата: 1.


ПРОВЕРКА КОДА ВОЗВРАТА
=======================

PowerShell:
  $LASTEXITCODE

Командная строка Windows (cmd):
  echo %ERRORLEVEL%

Linux/macOS:
  echo $?
