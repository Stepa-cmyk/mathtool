# Лабораторная работа № 1 «Решение уравнения»

Консольное приложение на Python для решения уравнений вида:

`A*x^2 + B*x + C = 0`

Студент: Гонжаленко Демид  
Группа: Б.ПИН.ИИ.26.16  
Направление: Программная инженерия

## Требования

- Python 3.12 или новее;
- дополнительные библиотеки не требуются.

## Состав проекта

- `main.py` — первая учебная программа для знакомства с Python;
- `mathtool.py` — приложение для решения уравнений;
- `tests.txt` — полный набор ручных тестов;
- `README.md` — описание проекта и инструкция по запуску;
- `.gitignore` — исключения для Git.

## Запуск

Показать справку:

```console
python mathtool.py
python mathtool.py --help
```

Ввести коэффициенты с клавиатуры:

```console
python mathtool.py solve
```

Передать коэффициенты в командной строке:

```console
python mathtool.py solve -a 1 -b -3 -c 2
```

В Linux команда `python` при необходимости заменяется на `python3`.

## Возможности приложения

- решение квадратных уравнений;
- решение линейных уравнений при `A = 0` и `B != 0`;
- вычисление и вывод дискриминанта;
- вывод корней с точностью до трёх знаков после запятой;
- сообщение об отсутствии действительных корней;
- проверка целочисленного формата коэффициентов;
- проверка диапазона от `-10000` до `10000` включительно;
- обработка неизвестных команд и неверных параметров;
- раздельный вывод результатов и сообщений об ошибках.

## Коды возврата

- `0` — программа успешно выполнила команду;
- `1` — обнаружена ошибка в команде, параметрах или исходных данных.

Отсутствие действительных корней не считается ошибкой, поэтому в этом случае
программа возвращает код `0`.

## Тестирование

Все обязательные сценарии и ожидаемые результаты приведены в `tests.txt`.
После каждого запуска код возврата можно проверить следующей командой:

```powershell
$LASTEXITCODE
```

В командной строке Windows используется `echo %ERRORLEVEL%`, а в Linux —
`echo $?`.
